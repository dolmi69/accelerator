# Конструктор Django: библиотека готовых модулей

Лаборатория сохраняет статический HTML или самостоятельное Django-приложение.
Готовый Python находится в `founder/blueprints/django_basic`. Qwen создаёт/правит
только главную страницу; модели, миграции, права и маршруты модели не генерируют.

## Использование

В лаборатории откройте «Разработка прототипа» → «Встроенные инструменты» →
«Возможности сайта», выберите модули и сохраните. Оформление находится в соседнем
блоке. Поле запроса остаётся основным способом доработки; тип сайта наследуется
от выбранной версии, блок для правки определяется автоматически.
Создаётся отдельная версия без AI. Затем нажмите «Запустить на весь экран».
Сайт открывается поверх лаборатории в той же вкладке. Крестик, кнопка возврата,
Esc (в том числе внутри сайта) закрывают просмотр;
выбранная версия, введённый запрос и прокрутка лаборатории сохраняются.
Выход из просмотра не останавливает сервер. В отдельно открытом локальном сайте
также есть кнопка «Вернуться в лабораторию». Макет без бэкенда можно развернуть
кнопкой под предпросмотром.
При первом запуске откроется создание владельца — отдельного аккаунта сайта.
Через «Кабинет» можно добавлять карточки, смотреть заявки, заказы и записи;
через «Команда и права» — приглашать зарегистрированных участников и назначать
сотрудников. В профиле доступны логин, имя, описание, email и аватарка.

В группе «Базовые возможности» заранее отмечены регистрация, сброс пароля,
чаты и уведомления; каждую функцию можно отключить. Вход владельца, профиль
и управление ролями сохраняются. «Основы маркетплейса» — каталог/поиск,
заявки, файлы и публикации. Остальные группы — работа с клиентами и продажи.
Зависимости (например, каталог для избранного) устанавливаются автоматически.

Поле `LabSiteVersion.backend_modules` сохраняет набор для каждой версии;
экспортируемый `site.json` содержит нормализованный список. Правки оформления
и HTML наследуют набор. Отключение не удаляет таблицы или данные, но закрывает
маршруты и убирает интерфейс. Новая версия использует прежнюю DB,
файлы, секрет и имена cookies.

## Расход токенов

Выбор модулей и следующие команды выполняются локально:

- «добавь регистрацию и сброс пароля»;
- «добавь каталог и избранное»;
- «подключи заявки и бронирование»;
- «добавь корзину и заказы».

Диспетчер `services/backend_modules.py` распознаёт ограниченные команды
из списка. Смешанные/неизвестные требования (Google login, оплата в долларах,
изменения цвета одновременно с модулем) не считаются полностью выполненными
шаблоном и продолжают обычный путь редактора. Новая нейронка для классификации
не подключена. По повторной отправке сохранённая настройка переиспользуется.
Нулевые токены установки не означают бесплатный хостинг, почту или платёжный сервис.

## Границы и проверки

- Рабочие модули расположены вне AI iframe, в доверенных Django-шаблонах.
- Встраивание локального бэкенда разрешено через CSP только из явно указанного
  локального адреса лаборатории. Контекст `.lab-viewer.json` не экспортируется;
  в публичном режиме интерфейс возврата отключён. Сообщение о закрытии проверяется
  по отправившему iframe и origin; AI макет остаётся в sandbox с непрозрачным origin.
- Владелец подтверждается одноразовой ссылкой; публичная регистрация не даёт прав.
  Приглашение закреплено за конкретным аккаунтом, ограничено сроком и одноразовое.
- Заявки/переписки/заказы не показываются другим участникам. Владелец и сотрудники
  управляют бизнес-данными сайта. Роли проверяются сервером.
- Галерея доступна вместе с опубликованной карточкой, остальные файлы скачиваются
  только через проверку доступа. Максимальный размер файла 5 МБ.
- Бронирование и заказ транзакционные; цена вычисляется сервером,
  повтор заказа идемпотентный, отмена возвращает остатки один раз.
- Платёжная интеграция выключена без собственных ключей. Webhook не доверяет
  присланному статусу, подтверждение проверяется через API ЮKassa. Проверена
  тестами с ответами-заготовками; живой магазин не подключался.
- Почта по умолчанию локальная (журнал), для доставки нужен SMTP своего сайта.
- Отдельный процесс не наследует API-ключи и DB ускорителя. ZIP содержит только
  исходники и `.env.example`, без пользователей, файлов, `.env` и локальных секретов.

Файлы запуска: `.runtime/lab-backends/<startup UUID>/project/`;
журнал: `.runtime/lab-backends/<startup UUID>/server.log`.
Локальный запуск доступен только с Mac/Linux на loopback, до трёх проектов.
Публичная карточка ускорителя показывает sandbox главной страницы; это не
облачный хостинг нового бэкенда. Для нескольких ASGI workers нужен Redis.

Проверки ускорителя: `python manage.py test founder.test_django_builder founder.test_lab founder.test_lab_costs`.
Проверки скачанного проекта: `python manage.py test core`.

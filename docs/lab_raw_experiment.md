# Временное сырое тестирование моделей — 13.10.2026

14.10 по просьбе Эльдара дополнительно включён локальный тест без наших бюджетных и количественных ограничений, ответ до 128 000 токенов. Счётчик текущего теста сброшен. Режим и возврат прежних ограничений: [lab_unrestricted_test.md](lab_unrestricted_test.md).

В локальном .env включён LAB_RAW_AI_TEST_MODE=1. Все встроенные инструменты временно отключены по просьбе Эльдара. Вернуть обычную лабораторию: LAB_RAW_AI_TEST_MODE=0 и перезапуск сервера. Веса модели не изменяются.

Для локальных тестов 14.10.2026 также установлен `LAB_REQUESTS_PER_DAY=0`: персональная суточная квота лаборатории отключена. Старый лимит 10 попыток включал неудачные генерации и блокировал следующий запрос до обращения к Ofox. Существующие счётчики сохраняются; установка 0 позволяет продолжать работу без их удаления. При возвращении обычного режима отдельно восстановить `LAB_REQUESTS_PER_DAY=10` (или выбранную квоту) и перезапустить сервер. Это настройка только локального `.env`; в `.env.example` остаётся обычное значение 10.

После повторной остановки FAQ на Luna Эльдар подтвердил постоянный переход на GPT‑6.1 Sol через Ofox (14.10). Активная модель, тариф и лимит ответа описаны в `docs/ofox.md`. В форме видна модель следующего запроса, у результата — модель сохранённой версии. Сырой режим продолжает работать без готовых инструментов и шаблонов.

Позднее 14.10, после добавления удаления проектов, Эльдар попросил вернуть GPT‑6 Luna. Сейчас активна `openai/gpt-6-luna`, тариф $0.10/$0.50 за миллион входных/выходных токенов. Responses API и уровень рассуждения medium сохранены. История тестов Sol остаётся в `docs/ofox.md`.

Сохранены исходники Django blueprint, каталог компонентов founder/design_guides/components, правила дизайна и бесплатные диспетчеры. Их не удалять. В сыром режиме новые версии их не используют:
- нет окна Инструменты и подключения модулей;
- нет автоматической регистрации, каталога, стартовых записей и бронирования;
- нет локальных замен текста/оформления, route=template и кеша генераций;
- модель возвращает полный HTML/CSS/JS при создании и каждой доработке;
- нет библиотеки Forge, готовых дизайн-примеров и локальной починки взаимодействий;
- вопросы тоже идут модели; остаётся разделение обсуждения и изменений;
- отчёт, версии, учёт токенов, изоляция, защита ключей и проверка назначения сохраняются.

Это тест дизайна и клиентской логики. Настоящая база, регистрация, серверные бронирования и платёжные операции не появляются от HTML. Модель обязана обозначать такие интерфейсы как демонстрационные. Проверка больше не требует /catalog/ и /bookings/ от статического сайта.

Старые версии и базы Django не изменяются. Возврат к старой версии позволяет пользоваться ранее подключёнными модулями. Новый результат сохраняется как статический сайт. Идентичный промпт сознательно запускает новое платное обращение; автоматических повторов нет.

Обычные тесты запускаются с экспериментом выключенным, а founder.test_lab_raw явно включает флаг для проверки нового пути. Контроль: повторная генерация, полное тело исходника, закрытые endpoint инструментов, вопрос через модель, сохранение старого сайта при ошибке.

## Расход и сбой провайдера

Счётчик показывает стоимость, рассчитанную по полученным входным/выходным токенам; это оценка по локальному тарифу. Неподтверждённые резервы вынесены отдельно и продолжают ограничивать бюджет. Не считать их списанием Ofox. Структурные метаданные новых ответов (статус завершения, число вариантов, длина текста, токены) сохраняются в .runtime/lab-ai-diagnostics; без промптов, кода или ключей. Совместимый API может пропустить finish_reason: непустой текст всё равно проверяется на JSON/полный документ; явная ошибка или пустой результат не применяются.

Позднее 14.10 Эльдар запросил Claude Sonnet 5.5. Активная модель теперь `anthropic/claude-sonnet-5.5` через Ofox, тариф $2/$10 за миллион входных/выходных токенов. Сырой статический режим не изменён. Подключение и история моделей описаны в `docs/ofox.md`.

Последнее переключение 14.10: Эльдар предпочёл GPT‑6.1 Sol результату Sonnet. Активна `openai/gpt-6.1-sol`, Responses API, reasoning medium; безлимитный локальный эксперимент и текущий отсчёт расходов сохранены.

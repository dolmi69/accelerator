## Проект и текущая задача

лаборатория создаёт HTML-прототипы и подключает готовые Django-модули.
Эльдар отвечает за лабораторию. Сейчас задача ограничена техдолгом и Windows;
большой редизайн и замена модели в эту задачу не входят.

Последний локальный коммит на момент снимка: `72cb188` — `merge 2`, ветка `main`.
Последующие исправления лаборатории, адаптация Windows и эта памятка ещё не

Проверьте, что в перенос попали новые файлы, а не только изменения старых.

## Перенос файлов и данных

1. Перенесите актуальную папку `cofounder_ai` либо сохраните код в Git и клонируйте
   соответствующий коммит. Последние незакоммиченные файлы обязательно включите.
2. Не переносите `.venv`, `node_modules`, `__pycache__` и Mac-инструменты `.tools`.
   Установите Python 3.14 с Launcher и Git. `setup.bat` создаст Windows-окружение;
   `start.bat` запустит сайт. Node 22 нужен для JS-тестов.
3. Для прежних аккаунтов, проектов, переписок и версий лаборатории нужна копия
   `db.sqlite3`, а для загруженных файлов — `private_uploads`. SQLite копируйте
   после остановки серверов или через SQLite backup; не собирайте снимок живой БД
   простым копированием одного файла.
4. В дочерних сайтах собственные данные лежат в
   `.runtime/lab-backends/<id>/project/db.sqlite3`, файлы — в `project/uploads`.
   Сохраняйте их отдельно после остановки сайтов. Состояния процессов
   `runtime.json`, номера PID, lock-файлы и прежние локальные адреса не переносите
   как состояние работающих серверов. Код дочернего сайта пересоздаётся из версии.
5. `.env` с ключами переносите приватно между своими компьютерами или настраивайте
   заново; в Git и в чат ключи не отправляйте. Сверьте настройки путей и Redis:
   Mac-пути и недоступный Redis потребуют изменения. Модель Qwen и цены заданы
   локально в `.env`, клонирование GitHub само по себе их не перенесёт.

Открытие папки в новом чате даёт доступ к файлам; оно само по себе не переносит
всю переписку прежнего чата. Прочитайте эту памятку, `docs/windows.md`,
`docs/product_direction.md`, затем проверьте код и актуальные изменения.

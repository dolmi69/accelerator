# «Свежий взгляд»: план на день

Карточка на радаре заменяет старый пересказ обзора проекта. «Составить план с Бруно»
или «Обновить план» делает один явный AI-запрос. GET не запускает генерацию.
startup.daily_plan сохраняет дату, фактическую модель, краткий фокус и 1–3 действия.
Вчерашний план помечается своей датой; он не выдаётся за сегодняшний.

Контекст: сохранённый разбор проекта без дополнительного извлечения экономики,
до 20 открытых задач из рейтинга RICE/ICE (с каноническими оценками функций MVP),
активные соавторы и исполнители. Модель выбирает ключи доступных действий, пишет
заголовки и пояснения. Ссылки и ID задач определяет сервер. Для распределения задач
нужен активный соавтор и хотя бы одна задача без исполнителя. Опросы Кано отключены
и не входят в задачи для выбора.

Строгая проверка отклоняет неизвестные ключи, повторные/пересекающиеся задачи,
неполные поля и слишком длинный ответ. Ошибка сохраняет прежний план. Сохранение
проверяет прежнюю версию JSON, чтобы параллельный запрос не затёр более новый план.
Повторов AI-запроса в этом сервисе нет. Применяются общие лимиты и AI-lease.

Задачи, их оценки и исполнители не меняются при генерации плана. Прогресс берётся
из фактических статусов задач. Декоративный Бруно использует существующий маскот
и аксессуары. Команда остаётся справа в своей колонке, мобильный вид — одна колонка.

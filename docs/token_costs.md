# Экономия токенов и контроль расходов

## Что работает

- Готовая основа Django, регистрация, WebSocket-чаты, запуск и экспорт используют 0 AI-токенов.
- Бесплатный редактор меняет название, общую палитру, шрифт и форму кнопок. Версии остаются в истории. Простой запрос «поменяй цветовую гамму на синюю» распознаётся локально; смешанные задачи не подменяются одной настройкой.
- Обычная AI-доработка возвращает только точные замены, максимум 2048 выходных токенов вместо 6144 для полной генерации. Проверяются однозначность размещения всей группы замен, отсутствие пересечений и целостность документа. Если фраза повторяется в разметке и скрипте, правка принимается только при единственном возможном размещении всех замен. При ошибке нет автоматического платного повторения.
- Для большого сайта нужно выбрать блок; в запрос передаётся выбранный HTML, а не весь сайт. Фрагменты берутся из исходной версии, правки применяются к ней без выполнения сгенерированного Python/выражений. Полная пересборка включается пользователем явно.
- Повтор одинакового запроса к той же исходной версии в рамках одного проекта открывает сохранённый результат. Данные пользователей между собой не кешируются. Для другого результата нужно изменить задание.
- История обычного чата Бруно ограничена 20000 символами: сохраняются последняя реплика и недавние сообщения. Прежние слова пользователя остаются в БД и подбираются поиском по памяти. Это уменьшение входного контекста, а не гарантия, что модель никогда не забудет деталь.

## Журнал и ограничения

`LabAIUsage` хранит каждую попытку Qwen, тариф на момент запроса, фактические токены при наличии, резерв, результат и связь с сохранённой версией. Неудачные запросы тоже учитываются. Отсутствие токенов означает неизвестный расход, а не ноль. Старые версии до этого обновления не включаются задним числом в финансовый журнал.

`LabSpendBucket` атомарно резервирует деньги до отправки запроса: отдельные лимиты дня/месяца пользователя и всего сервиса, плюс лимит одной операции. После ответа известный расход уточняется; повторная обработка не возвращает резерв дважды. CLI использует общий бюджет. Квоты по количеству запросов остаются дополнительной защитой; бесплатные правки и кеш их не расходуют.

При таймауте, потере ответа или остановке процесса резерв сохраняется. Такие записи надо сверять с кабинетом провайдера: программа не может узнать, оплатил ли провайдер запрос без ответа. Платных повторов по умолчанию нет.

До ответа резерв рассчитывается по UTF-8 байтам контекста с запасом на служебные поля и максимальному выходу. Это консервативная оценка без токенизатора, **не абсолютная гарантия верхней границы счёта провайдера**. Журнал показывает расчётную стоимость, не банковские списания и не выставленный пользователю счёт. Если фактическая стоимость превысит резерв, она будет отражена, и дальнейшие запросы могут быть заблокированы.

По умолчанию: 10 ₽ на запрос, 20 ₽/день и 100 ₽/месяц на пользователя, 200 ₽/день и 2000 ₽/месяц на весь сервис. Настройки в `.env.example`. 0 блокирует платные вызовы; бесплатный редактор продолжает работать. Это ограничения для MVP, не тариф подписки и не индивидуальные платные права доступа.

## Тариф

Для **нативной** `Qwen/Qwen3-Coder-Next`: вход 122 ₽, выход 244 ₽ за миллион токенов, с НДС; дневной тариф Cloud.ru проверен 07.10.2026. Ночные скидки не закладываются. Источник: https://cdn.cloud.ru/docs/legal/tariffs/evolution/current-version/foundation-models.pdf . При изменении модели нужно явно обновить `QWEN_PRICE_MODEL`, `QWEN_INPUT_RUB_PER_MILLION`, `QWEN_OUTPUT_RUB_PER_MILLION`; неизвестная модель блокируется до настройки цены.

Пример с подтверждённым usage: 4000 входных + 2000 выходных = 0,976 ₽. Это иллюстрация, не обещание средней стоимости генерации.

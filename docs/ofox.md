# Лаборатория через Ofox

Подключено 13 октября 2026 с Luna. После сравнений Luna, Sonnet 5.5 и Sol **14 октября по последнему выбору Эльдара основной генератор лаборатории возвращён на `openai/gpt-6.1-sol`** через `https://api.ofox.ai/v1`. Вопросы внутри лаборатории используют ту же модель; основной собеседник Бруно вне лаборатории продолжает использовать настройку `AI_PROVIDER`.

## Локальная настройка

Для текущего эксперимента по просьбе Эльдара включён `LAB_UNRESTRICTED_TEST_MODE=1`: расходы и число запросов не ограничиваются приложением, а предел ответа временно поднят до 128 000 токенов. Обычные значения ниже сохранены для возврата ограничений. Сброс счётчика и проверка режима описаны в [lab_unrestricted_test.md](lab_unrestricted_test.md).

В `.env`:

```dotenv
LAB_CODE_PROVIDER=ofox
OFOX_API_KEY=your-private-key
OFOX_CODE_MODEL=openai/gpt-6.1-sol
OFOX_CODE_API=responses
OFOX_PROVIDER_TYPE=
OFOX_CODE_REASONING_EFFORT=medium
OFOX_PRICE_MODEL=openai/gpt-6.1-sol
OFOX_INPUT_USD_PER_MILLION=2
OFOX_OUTPUT_USD_PER_MILLION=10
OFOX_USD_RUB_RATE=100
LAB_CREATE_MAX_TOKENS=16384
```

Ключ хранится на сервере. `.env` исключён из Git. Его нельзя вставлять в пользовательский сайт или передавать в промпте.

Тариф активной Sol — $2 за 1 млн входных и $10 за 1 млн выходных токенов, проверен 14 октября по каталогу Ofox. Тариф предыдущей Sonnet 5.5 такой же; Luna — $0.10/$0.50. `OFOX_USD_RUB_RATE=100` — явный расчётный курс для рублёвого учёта и ограничений приложения, не актуальная котировка валюты. Кэш учитывается по полному входному тарифу, поэтому оценка консервативная; фактическое списание смотрите в Ofox. Локальный лимит создания оставлен 16 384 выходных токена. В сыром режиме этот предел применяется и к доработкам, возвращающим полный документ.

По умолчанию используется Responses API: `max_output_tokens`, отдельные инструкции и история сообщений. Параметр `reasoning.effort` передаётся только моделям GPT‑6; для Sonnet 5.5 GPT-настройки рассуждений не передаются, используется обычный режим генерации. `store=false` отключает хранение ответа средствами Responses API. Для совместимости можно явно выбрать `OFOX_CODE_API=chat_completions`: тогда передаются `max_completion_tokens` и `reasoning_effort`. При включённом рассуждении `temperature` не передаётся. Число выходных токенов включает рассуждение. Сохранены ограничения токенов/бюджета, проверки полного HTML и отчёта, защита исходной версии и отсутствие автоматических платных повторов или переключения на другую модель.

`OFOX_PROVIDER_TYPE` оставлен пустым: канал выбирает Ofox. Не закреплять `openai` только на основании публичного каталога: в реальном запросе 14 октября этот канал вернул HTTP 400 / `provider_type_unavailable` для текущего доступа. Явно выбранный недоступный канал возвращает ошибку без смены модели. Настройка передаётся заголовком `X-OfoxAI-Provider-Type`.

Чтобы вернуть Cloud.ru, установите `LAB_CODE_PROVIDER=cloudru` и перезапустите сервер. Его модель и тариф остаются в `QWEN_*`. Кэш результатов различает провайдера, модель, уровень рассуждения, протокол API и выбранный канал.

## Проверка

Один короткий реальный запрос подтвердил соединение. Полноценный пример генерируется существующим `generate_site`, с теми же инструкциями и проверкой JSON/HTML/отчёта. Результат сохраняется в `assets/model-tests/ofox-gpt6-luna/`; пользовательские проекты для теста не заменяются.

14 октября выполнен контроль исходного запроса «Бери на время» в сыром режиме через Responses API. Ответ завершён (`stop`), 1 061 входной и 7 380 выходных токенов, 21 569 символов ответа. В проекте «бери на время(3)» сохранена статическая версия `c839853a-aec5-4a3b-b027-8866cda825ee`. Расчётная стоимость попытки — 0,379610 ₽. Поиск, сортировка и открытие товара проверены в браузере. Предыдущий Chat Completions ответ содержал 22 581 символ, но получил `content_filter` без категории и токенов; он не применялся. Успех новой попытки подтверждает работоспособность этого подключения, но не доказывает точную причину фильтра у провайдера и не гарантирует отсутствие будущих отказов.

Структурные сведения об ошибках и завершении сохраняются в `.runtime/lab-ai-diagnostics`, без промптов, кода и ключей. Фильтр, отказ модели, незавершённый или обрезанный ответ отклоняются в обоих протоколах.

Новая диагностика отдельно сохраняет безопасные идентификаторы провайдера, статус Responses, причину незавершённости и наличие отказа; отказ самой модели отличается от `content_filter`, тексты отказов не сохраняются в диагностике.

Журнал Ofox подтвердил фактическую стоимость теста Sol: **$0.07355680** (запись 14.10.2026, 01:51:00). Она отличается от рублёвого счётчика, который использует общий тариф каталога и не учитывает скидку канала/кэш. При условном локальном курсе 100 ₽/$ это около 7,36 ₽; не использовать эту конвертацию как актуальный валютный курс.

## Потоковое получение кода

`OFOX_CODE_STREAM=1` (по умолчанию) включает SSE для Ofox Responses API.
Сервер лаборатории получает фрагменты ответа постепенно; готовый JSON применяется
только после terminal event `response.completed`. `response.incomplete` и
`response.failed` проходят обычную проверку статуса и учёт usage; обрыв без
терминального события не сохраняет частичный код и оставляет списание неопределённым.
Автоматических платных повторов и переключений модели нет.

Это streaming между Ofox и нашим сервером, а не вывод сырого кода в интерфейсе.
В диагностике сохраняются число событий, время первого события/текста и длительность,
без содержания кода и ключей. Streaming не гарантирует обход серверного ограничения
провайдера на общую длительность запроса; длинную генерацию надо проверить отдельно.
Можно отключить через `OFOX_CODE_STREAM=0` и перезапуск. Chat Completions не изменён.

Документация: https://ofox.ai/docs/api/openai/responses
и https://developers.openai.com/api/docs/guides/streaming-responses

# Ручное редактирование AI-сайтов

Вход: «Визуальный конструктор → Редактировать AI-сайт вручную» у выбранной статической или сгенерированной версии лаборатории. Блочные версии продолжают открываться в блочном конструкторе. Предыдущие версии и его отдельный черновик не заменяются.

## Возможности

- Текст меняется прямо на холсте или справа; вложенные ссылки, выделения, ID и обработчики сохраняются.
- Картинки JPG/PNG/WebP из общей приватной библиотеки проекта заменяют img или встроенную SVG-иллюстрацию; доступны подписи и фоновые изображения.
- Цвет, фон, размер и семейство шрифта, насыщенность, выравнивание, отступы, расстояния, скругления, вписывание картинки, скрытие и возврат исходного элемента.
- Поиск по элементам, компьютер/телефон, отмена/повтор до 50 шагов, автосохранение и Cmd/Ctrl+S. Конфликт вкладок не перезаписывает чужой черновик; доступна JSON-копия своих правок.
- «Сохранить версию» добавляет неизменяемый снимок. «Проверить работу» открывает обычную лабораторию с действующим изолированным сервером. «Опубликовать» обновляет BrunoHost; автосохранение не меняет публикацию. Скачать можно готовый статический HTML или ZIP серверного приложения.

## Данные и сохранность

`LabManualDraft` (миграция 0043): отдельный черновик на исходную версию, JSON правок, ревизия и последний сохранённый снимок. До 200 изменённых фрагментов/элементов, 180 КБ JSON, 6000 символов на фрагмент; индексируется до 2500 исходных узлов.

`manual_site.Source` индексирует диапазоны исходника через HTMLParser. Сохраняются только явные замены текстовых диапазонов и выбранных открывающих тегов. DOM предпросмотра никогда не сериализуется в исходник. Для generated изменяется только index.html; app.py и файлы CSS/JS побайтно прежние. Предыдущий снимок не изменяется. Ручная версия расходует 0 токенов. Следующий запрос к AI получает уже изменённый код.

Картинки принадлежат проекту, повторно обрабатываются Pillow и помещаются в /assets/bruno-images/<uuid>.webp. В presentation.manual_assets хранится список изображений конкретного снимка. Код и AI-запросы не содержат огромных data-URI. Лаборатория, BrunoHost и ZIP получают только изображения своего проекта, на которые ссылается снимок. Непрозрачный предпросмотр сообщества и одиночный HTML используют переносимые data-URI. Следующая AI-версия восстанавливает список по сохранённым ссылкам. Приватные адреса загрузок не попадают в опубликованный HTML.

Повторные ручные снимки образуют цепочку версий. Локальный запуск ищет базу ближайшего запускавшегося предка, включая случай нескольких сохранений без запуска. BrunoHost продолжает использовать стабильную базу опубликованного сайта.

## Границы и изоляция

На холсте выполняется только просмотр HTML/CSS. Скрипты, активные обработчики, фреймы и автоматические переходы удаляются из отдельной копии; iframe разрешает same-origin для выделения, но запрещает scripts. Дополнительно ставится CSP script-src none / connect-src none. Формы, вычисляемые значения и наполнение, создаваемое JS, проверяются через «Проверить работу». Это редактор исходного HTML и оформления, а не серверных данных или кода приложения. Динамическая разметка, которой нет в HTML-исходнике, не превращается автоматически в редактируемые блоки. Статические сайты пока остаются одной HTML-страницей; создание страниц и новых блоков есть в отдельном блочном конструкторе.

Права повторяют редактирование проекта; владелец/редактор, CSRF и проверка ревизии обязательны. Допустимые свойства CSS и типы ссылок ограничены; пользовательские HTML/JS и чужие изображения не принимаются. Старые Django blueprint-версии остаются в прежнем режиме.

## Проверки

founder.test_manual_editor проверяет точные замены, вложенность и HTML-сущности, неизменность server/JS/CSS, отсутствие AI-вызовов, автосохранение/конфликты, снимки и цепочку источников, права/CSRF/JSON, SVG, CSP, загрузку и публикацию изображений, ZIP и приватность чужих/неопубликованных файлов. Реальный runtime-тест в test_generated_backend проверяет сохранение SQLite через несколько непросмотренных версий.

В Chrome на отдельной копии AI-калькулятора проверены текст и оформление, замена иллюстрации, версия и повторное открытие, действующий расчёт 150 × 3 = 450 ₽ с сохранением на сервере и переходом на следующую ручную версию. Проверены реальная публикация BrunoHost с отдельным файлом картинки и мобильная компоновка при ширине 390px. Платные AI-вызовы не выполнялись.

# Стартовые записи каталога

При запуске Django-сайта prepare_site создаёт три опубликованные редактируемые записи Item, если включён catalog и каталог ещё пуст. AI не вызывается. Категория выбирается локально по названию и короткому описанию проекта; неизвестная тематика получает универсальные примеры. Цены и описания явно обозначены как демонстрационные.

SiteControl хранит признак выполненного заполнения: повторные запуски и удаление примеров не добавляют их снова. Существующие товары не изменяются. Без catalog заполнение не выполняется.

До настройки владельца записи принадлежат отдельному неактивному аккаунту без пароля и прав. При получении доступа владельца записи переходят ему. Можно отредактировать или удалить их через управление каталогом. Интервалы бронирования автоматически не создаются.

Работает в предпросмотре и скачанном Django-проекте. Статический HTML без серверного каталога не имеет базы товаров. HTML-карточки модели и записи Item остаются разными источниками: данная правка не импортирует произвольный HTML в базу.

Проверка: python manage.py test_blueprint (60 тестов, включая повторный запуск, удаление, существующий каталог, отключённый модуль и передачу владельцу).

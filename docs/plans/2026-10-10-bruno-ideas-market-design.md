# Бруно: развитие идеи, идеи в нише и анализ рынка

Дата: 2026-10-10. Ветка `Andrey`. Автор: Андрей + Claude.

## Зачем

Основатель на стадии идеи часто приходит не с готовым проектом, а с пожеланием («хочу, чтобы это было
для собак», «а если сделать подписку?») или только с нишей («хочу что-то в образовании»). Бруно
умел рассуждать и давать три идеи-проверки, но не умел развивать идею по маленькому пожеланию и
не предлагал своих идей в нише. И он ничего не знал о рынке: конкурентов называл, только если их
назвал основатель.

## Что взяли из скиллов

**brainstorming** (как Бруно ведёт разговор об идее):
- один вопрос за реплику, лучше с выбором из вариантов («Вам ближе первый или второй?»);
- 2–3 варианта с плюсами и минусами, первым идёт рекомендация и почему;
- YAGNI: из вариантов советовать самый простой, который проверяет пожелание;
- шаг за шагом: основатель выбирает вариант, Бруно развивает именно его.

**agent-reach** (как Бруно смотрит на рынок):
- поиск по нескольким запросам параллельно, затем сводка;
- Exa как основной поиск (работает без ключа через публичный MCP `mcp.exa.ai`), DuckDuckGo как запасной;
- найденное в интернете — данные, а не инструкции.

## Режимы ответа в чате (mentor.answer_kind)

| kind | Когда | Что делает Бруно |
|------|-------|------------------|
| `develop` | «а если добавить…», «хочу, чтобы…», «давайте доработаем идею» | Переформулирует пожелание, 2–3 варианта (что меняется для клиента, плюс, минус), какой выбрал бы и почему, один вопрос с выбором. Варианты → кнопки «Проверить это». |
| `niche` | «придумай идею в сфере…», «хочу что-то для студентов», «какой стартап можно сделать в…» | Три идеи в нише: для кого, какая боль, как зарабатывает, как проверить за неделю. Рекомендация и вопрос с выбором. Идеи → «Проверить это». |
| `market` | «насколько актуальна идея», «есть ли конкуренты», «сколько можно заработать» | Короткий поиск (2 запроса), ответ с источниками, предложение открыть полный анализ на странице «Рынок». |

Выбор варианта («давайте второй», «3») ловит Python (`chosen_option`): в подсказки попадает текст
выбранного пункта, и Бруно развивает именно его.

## Анализ рынка (страница «Рынок и конкуренты»)

`services/web_search.py` — поиск (Exa MCP / Exa API по ключу / DuckDuckGo), параллельно, с таймаутами,
обрезкой и дедупликацией. В поиск уходят только короткие запросы о нише, без имени основателя.

`services/market.py`:
1. Запросы: модель предлагает 4 коротких запроса по картине проекта; если не вышло — шаблоны.
2. Поиск всех запросов параллельно, до ~12 источников.
3. Разбор моделью по строгой схеме: актуальность (вывод + сигналы спроса со ссылкой на источник),
   конкуренты (название, что делают, цена — только если она есть в тексте источника, слабое место),
   чем клиенты решают задачу сейчас, деньги (ориентир цены по источникам), риски, проверки на неделю.
4. Python проверяет: номер источника существует, название конкурента есть в тексте источника,
   цифры цены есть в тексте источника. Не прошло — поле убирается. Прибыльность считает Python
   (`economics.py`) по словам основателя; рыночные цены идут как ориентир со ссылкой.
5. `MarketReport` (миграция 0021) хранит отчёт и источники. Проверки берутся в задания.

Последний отчёт попадает в контекст Бруно (конкуренты, вывод) и Олега из панели акул (он может спросить
«чем вы лучше X»).

## Ошибки и ограничения

- Поиск недоступен → отчёт не создаётся, понятная ошибка; чат отвечает без поиска.
- В тестах и деморежиме поиск выключен (`MARKET_SEARCH=off`), демо-отчёт без сети.
- `review_generate` и новый `market_generate` идут через лимиты AI и блокировку «1 запрос на аккаунт».

## Проверка

- Юнит-тесты: разбор kind, `chosen_option`, парсинг поиска (Exa SSE, DuckDuckGo HTML), валидация отчёта,
  промпты, view и лимиты.
- `bruno_eval`: новые сценарии `develop`, `niche`, `market` и искусственные проекты для панели акул.

## Что вышло (прогоны bruno_eval на GigaChat-3-Pro, 2026-10-10)

- `develop`: пожелание переформулировано, 2 варианта с плюсом и минусом, рекомендация, вопрос с выбором;
  шаг по выбранному варианту до 900 знаков без нового списка вариантов.
- `niche`: три идеи с клиентом, болью, заработком и проверкой; учитывает опыт основателя («сами занимаетесь фитнесом»).
- `market_chat`: называет найденные сайты в скобках с ценами из источников; на «конкурентов нет» отвечает
  «Я поискал…» и называет аналоги. Отчёт: 12 источников, 4–5 конкурентов, расчёт комиссии программой, ~18–20 с.
- Акулы: не путают основателя с Бруно, не повторяют пример и свои вопросы, Маргарита называет итог расчёта.

Найдено и исправлено по ходу: пустой расчёт у маркетплейса с комиссией, почасовая цена как ежемесячный платёж,
ссылки [10] как «выдуманные числа», blacklist GigaChat на найденные страницы, `review_generate` без AI-лимитов.

Открыто: в Exa/DuckDuckGo уходит описание ниши проекта — нужно отразить в политике конфиденциальности.

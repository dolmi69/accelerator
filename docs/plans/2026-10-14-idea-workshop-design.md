# Мастерская идей: дизайн

Дата: 2026-10-14. Ветка `Sharks`. Подход скилла brainstorming: формат выбрал Андрей
(«Мастерская идей», отдельный раздел в боковом меню проекта).

## Зачем

В чате Бруно уже умеет развивать идею (`develop`) и предлагать идеи в нише (`niche`).
Прогон `bruno_eval -s develop -s niche` 2026-10-14 прошёл без замечаний, но идеи
предсказуемые («челлендж в боте», «подписка», «лендинг с ценой»), без источников, а в
третьем ответе появились выдуманные цены (499 ₽, 790 ₽). Чату мешает формат: один
потоковый ответ, на мышление и поиск нет времени.

Мастерская — отдельная страница, где Бруно работает как креативщик и аналитик. Основатель
даёт зерно идеи, хоть одно слово («кофе», «как Авито, только для…», «студентам тяжело с
общагой»), и получает три разных направления с разбором и ссылками.

## Как Бруно думает (конвейер одного круга)

1. **Разбор зерна** (запрос к модели, JSON): как Бруно понял зерно, какая за ним боль или
   желание, и 4 поисковых запроса разных типов:
   - мир: похожие стартапы за рубежом (запрос на английском, у Exa английский индекс сильнее);
   - Россия: кто уже делает похожее и почём;
   - боли: отзывы, жалобы и обсуждения клиентов;
   - тренды: что меняется в этой сфере сейчас.
2. **Поиск** (`web_search.search_many`, Exa, без ключа): запросы параллельно, до 12 источников.
3. **Расходящееся мышление** (запрос с высокой температурой, обычный текст): 8 сырых идей,
   каждая своим приёмом: перенос модели из другой отрасли, инверсия, узкий клиент, другой
   плательщик, сделать вручную без кода, ERRC из «Голубого океана» (убрать, снизить,
   повысить, создать), 10× лучше по одному параметру, из жалоб в источниках, из зарубежного
   аналога. Текст списком надёжнее большого JSON для GigaChat.
4. **Сходящийся анализ** (запрос по строгой схеме): выбрать 3 самых сильных и разных,
   у каждого: суть, приём, клиент, кто платит и за что, чем клиент обходится сейчас,
   неочевидная мысль («почему сейчас / почему сработает»), главный риск, проверка за
   неделю с числом, направление радара, номера источников. Плюс выбор Бруно и почему.
5. **Проверка Python**: предложения с числами, которых нет в источниках, зерне и анкете,
   вырезаются (как в анализе рынка); номера источников проверяются; похвала и «ты»
   убираются; похожие названия направлений отбрасываются.
6. **Критик** (добавлен после первых прогонов): Python находит проверки-мнения («заплатили
   бы», «выразили желание», «согласились» без оплаты) и мысли из общих слов («многие люди»,
   «тренд растёт», «уникальный»); модель одним запросом переписывает только эти поля с
   диагнозом, новый текст принимается, если прошёл ту же проверку.

7. **Ловушки** (добавлено после прогонов): если warning пустой, отдельный короткий запрос
   проверяет причины неудач из источников «Кто пробовал и закрылся», уже существующие
   сервисы и ловушки из `idea_methods.TRAPS` («смоляная яма», «решение ищет проблему», «лужа»).

Мышление (приёмы, ловушки, вопросы оценки, «Спроси маму») собрано в
`founder/services/idea_methods.py` с указанием источников: эссе П. Грэма, доклад YC Дж. Фридмана,
«Голубой океан», Остервальдер, Фитцпатрик, ТРИЗ/SCAMPER.

У направления есть поле «Кто уже делает похожее»: без него модель не замечала конкурентов в
найденных источниках. Пожелание основателя — жёсткое условие для всех направлений.

## Итерации

- «Развить дальше» у направления: новый круг, зерно = это направление, плюс необязательное
  пожелание основателя («хочу дешевле», «для родителей»). Круг знает прошлые направления
  и не повторяет их.
- «Проверить это»: проверка направления становится заданием Бруно (как в анализе рынка).
- История кругов на странице.

## Данные

`IdeaRound`: startup, seed, wish, parent (круг, из которого развили), data (JSON: понимание,
направления, выбор), sources, queries, ai_model, created_at.

## Контекст

Анкета, картина проекта, свежий анализ рынка, прошлые круги. Если проекта ещё нет (только
зерно), Бруно работает от зерна.

## Деньги и лимиты

3 запроса к модели и 4 поисковых на круг. Маршрут `ideas_generate` в списке AI-маршрутов
(12/мин, 200/день, один запрос на аккаунт). В `manage.py test` поиск выключен.

## Проверка качества

`manage.py ideas_eval`: прогон конвейера на разных зёрнах (одно слово, «как X для Y»,
жалоба, развитие направления), отчёт в `.runtime/ideas_eval/`, автоматические замечания
(выдуманные числа, повтор направлений, нет источников, похвала, «ты»). Качество
креативности оценивается чтением отчёта.

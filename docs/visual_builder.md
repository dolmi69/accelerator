# Визуальный конструктор лаборатории

Вход: «Визуальный конструктор» над предпросмотром лаборатории. Рабочая ветка — `lab-visual-builder`. Изменения не отправлять в GitHub без просьбы Эльдара.

## Пользовательский сценарий

- Страницы: создание, адрес, описание для поиска, копирование и удаление с отменой.
- 11 типов блоков: навигация, первый экран, текст, преимущества, изображение, галерея, отзывы, тарифы, FAQ, призыв к действию, подвал.
- Содержимое и элементы карточек редактируются справа; текст также можно менять прямо на холсте. Блоки перетаскиваются в структуре, перемещаются кнопками, копируются и удаляются.
- Оформление блока: фон, выравнивание, отступы, композиция первого экрана. Тема сайта: акцент, фон, цвет текста, три семейства шрифтов, скругления.
- Компьютер/телефон, просмотр, отмена/повтор, автосохранение, Cmd/Ctrl+S, предупреждение о несохранённых данных. При конфликте вкладок черновик не перезаписывается; можно скачать локальную JSON-копию.
- «Сохранить версию» создаёт неизменяемую версию лаборатории. «Опубликовать» сохраняет и обновляет BrunoHost; автосохранение не меняет опубликованный сайт. Все страницы доступны по реальным путям, картинки — на том же отдельном домене. Вотермарка сохранена.
- ZIP содержит HTML всех страниц, относительные ссылки, изображения и JSON документа. Платформенный код, ключи и базы в архив не входят.

## Данные и границы

Миграция `0042_visual_builder`: `LabBuilderDraft`, `LabBuilderAsset`, `LabSiteVersion.builder_document`. Один структурированный черновик на проект; версия хранит снимок документа. До 20 страниц, 100 блоков, 200 КБ JSON; библиотека — до 100 изображений / 30 МБ на проект.

Картинки до 5 МБ / 20 Мп: Pillow декодирует JPG/PNG/WebP, снимает EXIF, уменьшает до 2400px, записывает WebP. SVG и произвольные файлы не принимаются. Файлы приватны; BrunoHost отдаёт только изображения, на которые ссылается опубликованный снимок. Удаление проекта очищает файлы после успешного завершения транзакции.

Редактор использует доверенный рендерер схемы и iframe `allow-same-origin` без скриптов. Пользовательские строки экранируются, CSS/JS не принимаются. Обычный предпросмотр конструктора также не исполняет скрипты. В сообществе изображения передаются уменьшенными data-URI, страницы переключаются доверенным обработчиком внутри существующей непрозрачной песочницы; приватные URL файлов не раскрываются.

Существующие произвольные AI-сайты не превращаются автоматически в блоки. При переходе из такой версии открывается отдельный блочный черновик, предыдущие версии сохраняются. Блоки тарифов и CTA содержат ссылки: платёжного сервера или обработки форм они не создают.

## Связка с AI

«Продолжить с Бруно» сохраняет снимок и открывает диалог лаборатории. Для структурированной версии AI возвращает операции над блоками и страницами вместо пересборки HTML/сервера. Валидируется весь документ; остальные поля сохраняются. До трёх исправлений завершённого некорректного ответа, все расходы учитываются. Модели и лимиты прежние. Незавершённый/запрещённый ответ не повторяется автоматически.

AI-версия обновляет черновик только если тот ещё соответствует исходной версии. Более новые ручные правки остаются нетронутыми, открытая устаревшая вкладка получает конфликт сохранения.

## Проверки

`founder.test_visual_builder`: права и CSRF, конфликт ревизий, неизменяемость снимков, нормальный экран лаборатории и CSP, изображения/подмена формата/чужие файлы, многостраничный BrunoHost, приватность черновика, ZIP, работа со структурированным AI-ответом и сохранение новых ручных правок. AI проверяется с заглушками без расходов.

Полный финальный прогон: 902 теста проекта; дополнительно 60 blueprint и 58 Node. После добавления ограничения вложенности JSON повторены тесты конструктора. В Chrome проверены: создание второй страницы, редактирование на холсте и в панели, загрузка собственного изображения, отмена/повтор, смена шрифта, мобильная ширина 390px, сохранение/перезагрузка, версии, публикация на отдельном домене, живые переходы /about/, обычный предпросмотр лаборатории и многостраничный просмотр сообщества с картинкой. Платные AI-вызовы не выполнялись.

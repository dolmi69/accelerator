# Работа над проектом

Объединяет прежние «Разбор и план», «Задания Бруно» и «Функции MVP».
Канонический адрес сохранён: `/startups/<id>/tasks/`. Старый `/review/?id=...`
открывает тот же интерфейс с выбранным историческим разбором.

## Главный экран

Общий рейтинг показывает все открытые задания Бруно и ещё не начатые функции MVP.
У задач рынка, экономики, команды и опросов есть собственные RICE/ICE (TaskEstimate).
Связанная с MVP задача использует оценки своей функции и появляется в рейтинге один
раз. Сортировка работает по всему списку. Ниже остаются компактные карточки заданий.

У разработки MVP есть метка «Можно выполнить в лаборатории!» и кнопка «Выполнить».
Она открывает лабораторию с редактируемым промптом до 2000 символов, без отправки
AI-запроса. Функции, состав MVP и опросы Кано доступны в отдельном свёрнутом блоке.
Подробности: `task_priorities.md`.

После явного запуска одного AI-запроса валидные шаги сразу становятся заданиями.
Уже открытые задания сохраняются; ограничение одного Bruno-задания на направление
предотвращает накопление повторных действий. Остальные шаги доступны внутри разбора.

Выбранный RICE/ICE передаётся при получении задач. Модель получает рассчитанный рейтинг,
MoSCoW и Кано, связывает шаг с функцией через проверяемый ID своего проекта.
Бруно предлагает исходные оценки с объяснением и пометкой предположений. Python
проверяет числа и считает баллы, ручные значения основателя имеют приоритет.
Открытие страницы и смена метода AI не вызывают.

Визуальные ориентиры: компактные списки Linear (linear.app/docs/display-options)
и таблица приоритетов Productboard (productboard.com/prioritize-features/).
Основой остаётся сохранённая разметка проекта от 15 октября 2026.

## Один разбор

Кнопка «Получить/Обновить разбор» вызывает `services/review.create_review`.
Один запрос к текущему AI-провайдеру Бруно возвращает вывод, риски, цель, шаги
и до пяти текстовых предложений функций с парными вопросами Кано. Если разработка
сейчас не нужна, список функций может быть пустым. Ответ полностью проверяется
до сохранения. В каждом шаге и новой функции есть отдельный блок estimate; такие
числа хранятся как предложения Бруно, отдельно от ручного ввода. Ответ также
оценивает существующие пункты проекта. Неявного повтора запроса
при ошибке формата больше нет. Ошибка не удаляет предыдущий разбор.

В контекст входят описание и картина проекта, разговоры, оценки радара, дневник,
сохранённое исследование рынка, задания, функции и оценки основателя, а также
независимые состояния проекта и выбранный фокус. Открытие страницы не вызывает AI.

Разбор хранится в существующем `ProjectReview`. Внутренний `_context_digest`
помогает показать предупреждение об изменившихся данных. Старые разборы доступны,
для них актуальность неизвестна. Повторного запроса без кнопки нет.

## Решения основателя

- После получения плана шаги автоматически добавляются в работу. Дополнительный
  шаг можно добавить из свёрнутого разбора по «Взять в работу» без AI.
  `_accepted_steps` в разборе предотвращает повторное создание даже после
  завершения/откладывания задания. Существующее ограничение одного открытого
  задания Бруно на направление сохраняется.
- «Добавить предложения в список MVP» читает сохранённый разбор, не обращаясь к
  AI. Повторный клик не создаёт дубликаты и не заменяет описание/оценки существующих
  функций. Числа, ручной MoSCoW, результаты Кано и связанные задания сохраняются.
- RICE/ICE и таблица Кано по-прежнему рассчитываются Python. Перенос Must/Кано
  в задания работает как раньше. См. `mvp_prioritization.md`.
- Смена фокуса сохраняется без AI. Для пересмотра выводов нужна кнопка обновления.

Исследование рынка, дневник результатов и тренировка питча находятся во внутренней
навигации рабочей области. Поиск по источникам и диалоги инвестора запускаются
отдельно по явному действию, поскольку это самостоятельные сценарии.

Наблюдатели могут читать, владелец и соавторы — менять. Доступ к разборам,
заданиям и функциям всегда ограничен текущим проектом. Существующие ограничения
запросов и блокировка одновременного AI-запроса действуют на общий разбор.

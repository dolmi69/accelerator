# Тестирование прототипов

Владелец выбирает версию в разделе «Разработка прототипа», указывает «Приватно» или
«Для всех» и нажимает «Добавить в карточку». Приватный прототип виден только владельцу,
в том числе через прямые ссылки. Режим «Для всех» открывает доступ участникам после
публикации самой карточки; карточка автоматически не публикуется. Новые генерации
остаются черновиками. Скрытие прототипа, переход в приватный режим, снятие карточки
с публикации или смена версии закрывают доступ посторонних к прежнему тесту.
Сохранённые результаты не удаляются. У существующих публикаций сохранён прежний
публичный режим; новая форма по умолчанию предлагает приватный.

Лаборатория состоит из разделов «Разработка прототипа» и «Глобализация».
Обратная связь и выбор версии для анализа находятся в «Глобализации».
История версий свёрнута внизу. Переключение разделов в браузере сохраняет
несохранённый запрос и параметры инструментов; ссылки работают и без JavaScript.

Карточка содержит изолированный предпросмотр без сбора действий и ссылку на тестирование. Сбор начинается только по кнопке «Начать тест». Записываются открытие страницы, клики по интерактивным элементам (статическая подпись и структурный путь), ступени прокрутки, попытки отправить форму и количество ошибок. Значения полей, пароли, IP, движения мыши и запись экрана не сохраняются. Формы прототипов демонстрационные, сетевые запросы заблокированы.

Прототип по-прежнему выполняется в iframe с непрозрачным origin и CSP `sandbox allow-scripts`, без доступа к сессии платформы. Внедрённый небольшой скрипт передаёт события через postMessage; родитель проверяет окно-источник, канал сессии и ограниченную схему. Сервер проверяет пользователя, текущую публикацию, CSRF, размер и типы данных. Максимум 200 событий на тест, 25 на пакет, 30 минут записи и 30 начатых тестов на аккаунт в сутки. Номера событий уникальны: повтор пакета не увеличивает показатели.

Статистика по выбранной версии и последние отзывы видны владельцу в лаборатории. Повторные тесты и уникальные участники считаются отдельно; проверки самого владельца исключены из основных показателей. Данные поступают из браузера и могут быть неполными или подделанными: это исследовательские наблюдения, а не доверенный аудит или доказательство спроса. Денежные награды за события не начисляются.

Бруно получает ограниченную сводку текущей опубликованной версии через общий контекст дневника: показатели, популярные элементы и до пяти отзывов. Контекст используется чатом, радаром, заданиями и разбором проекта. Сбор событий сам по себе не вызывает платный API и не меняет радар. Для анализа пользователь запускает обычный чат/разбор. Исходные отзывы помечены как непроверенный контент.

Проверки: `python manage.py test founder.test_lab_testing founder.test_lab`. Покрываются публикация и отзыв доступа, изоляция проектов и сессий, CSRF, ограничения событий, повторная доставка, исключение владельца и передача сводки Бруно. Реальный iframe дополнительно проверен в браузере.

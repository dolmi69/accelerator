# Анимации мастерской Бруно

- `forge-v1-business.html` — сохранённая первая версия в деловом костюме. HTML и CSS внутри файла; открывается без сервера.
- `forge-v2-blacksmith.html` — вторая версия: мультяшные пропорции, рубашка с закатанными рукавами, кожаный фартук и наручи.

- `forge-v3-claude.html` — исходный файл новой анимации, полученный от команды; сохранён без изменений. Сейчас подключён к лаборатории.

Файлы — самостоятельные снимки вариантов. Рабочая анимация лаборатории находится в `templates/founder/_bruno_forge.html`, движения активной версии — в `static/founder/css/bruno-forge.css`. V1 и V2 сохранять для сравнения. При изменениях интеграции исходный V3 не перезаписывать.

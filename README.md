# Co-Founder.AI — локальный MVP

Рабочий прототип на Django: регистрация, разговор с Бруно, таблица профиля по пяти направлениям с ручной и AI-оценкой, реакция маскота. В профиле доступны задания Бруно, дневник доказательств и тренировка разговора с инвестором о продажах.

## Запуск на Mac

В Терминале перейдите в папку проекта и выполните:

```bash
cd /Users/eldar/.codex/.chatgpt-projects/g-p-6ab4fa052e48819190434515759511ce/cofounder_ai
.venv/bin/python manage.py runserver
```

Откройте http://127.0.0.1:8000/ и создайте аккаунт. Зависимости уже установлены в `.venv`, миграции уже применены к локальной SQLite.

Если понадобится восстановить окружение:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python manage.py migrate
```

## Подключение настоящего ИИ

Без ключа приложение работает в **деморежиме**. Его ответы и отчёт создаются локальными простыми правилами; это позволяет проверить интерфейс, но не заменяет полноценный AI-анализ.

### GigaChat

На Mac можно открыть [configure_ai.command](configure_ai.command) двойным нажатием: мастер сам создаст приватный `.env`, спросит вид доступа и сохранит ключ. Затем перезапустите сервер. Если macOS не запускает файл двойным нажатием, в Терминале выполните `./configure_ai.command`.

1. Если у вас уже есть **ключ авторизации прямого GigaChat API**, следуйте [официальной инструкции](https://developers.sber.ru/docs/ru/gigachat/individuals-quickstart). Это ключ API, а не адрес будущего сайта.
2. Скопируйте `.env.example` в `.env` и установите `AI_PROVIDER=gigachat`, `GIGACHAT_CREDENTIALS=ваш_ключ`.
3. Оставьте `GIGACHAT_SCOPE=GIGACHAT_API_PERS` для ключа физлица. Для бизнес-ключа выберите `GIGACHAT_API_B2B` или `GIGACHAT_API_CORP` согласно типу проекта в личном кабинете.
4. Перезапустите сервер. Надпись «ДЕМОРЕЖИМ» в чате должна смениться на «GIGACHAT».

Ключ храните только локально в `.env`; не вставляйте его в чат или репозиторий. Если появится ошибка проверки сертификата, скачайте доверенный PEM по [инструкции GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates) и задайте `GIGACHAT_CA_BUNDLE=/абсолютный/путь/к/файлу.pem`. Проверка TLS в проекте не отключается. Библиотеку GigaChat SDK мы не используем: её документация указывает поддержку Python до 3.13, а здесь установлен Python 3.14; REST API работает напрямую.

Если вы **новый клиент**, GigaChat направляет оплату моделей через Cloud.ru. Для этого варианта получите сервисный API-ключ по [инструкции Cloud.ru](https://cloud.ru/docs/foundation-models/ug/topics/quickstart), затем установите в `.env` `AI_PROVIDER=cloudru` и `CLOUDRU_API_KEY=ваш_Key_Secret`. Модель по умолчанию — `ai-sage/GigaChat3-10B-A1.8B`; при необходимости измените `CLOUDRU_MODEL`. Это отдельный ключ: он не подходит для `GIGACHAT_CREDENTIALS`.

### Другие провайдеры

Создайте `.env` на основе `.env.example`. Для OpenAI задайте `AI_PROVIDER=openai` и `OPENAI_API_KEY`. Для Anthropic — `AI_PROVIDER=anthropic` и `ANTHROPIC_API_KEY`. Модели меняются через `OPENAI_MODEL` и `ANTHROPIC_MODEL`. По умолчанию указаны `gpt-4o` и `claude-sonnet-4-6`. Claude 3.5 больше недоступен в Claude API.

Не добавляйте `.env` в Git. Пользовательские файлы сохраняются в `private_uploads/` и не публикуются через статические URL.

## Telegram на локальном Mac

Бот — простой вход в тот же сайт: `/start`, `/app` и кнопка меню открывают Mini App. Внутри используются обычные аккаунты сайта; Telegram не создаёт отдельные проекты или пользователей автоматически.

Для запуска откройте `start_telegram.command` двойным нажатием. Токен берётся из `.env` (`TELEGRAM_BOT_TOKEN`). Скрипт запускает сайт на `127.0.0.1:8001` с той же базой, временный HTTPS-туннель Cloudflare и бота. Обычный сайт на порту 8000 продолжает работать отдельно. Кнопка в меню бота обновляется новым адресом при каждом запуске. Старые кнопки в сообщениях могут указывать на завершённый туннель — отправьте `/start` снова.

Mac должен быть включён и подключён к интернету; остановка скрипта закрывает временную ссылку. Это режим проверки, а не постоянный хостинг. В туннеле DEBUG выключен, токен не отправляется в браузер, доступ к проектам требует входа. Через Quick Tunnel чат получает готовый ответ целиком, поскольку этот вид туннеля [не поддерживает SSE](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/).

Логи находятся в `.runtime/`. Локальный файл `.tools/cloudflared` установлен из официального выпуска Cloudflare. Для постоянного сайта задайте `TELEGRAM_MINI_APP_URL=https://ваш-домен/`, выполните `manage.py configure_telegram_bot`, затем запустите `manage.py run_telegram_bot` отдельным процессом. Используйте только один процесс получения обновлений на токен.

## Текущий сценарий Бруно

После создания стартапа сразу открывается беседа с Бруно. Основатель рассказывает о сервисе своими словами, а Бруно задаёт уточняющие вопросы. Консультации и записи встреч для этой оценки не требуются. Кнопка «Составить таблицу» после первого сообщения анализирует описание стартапа, последние 25 сообщений основателя и до 6 подходящих более ранних заметок. Бруно возвращает пять оценок от 0 до 100, краткое объяснение каждой и общий вывод по имеющимся сведениям. Пятый пункт — ясность объяснения идеи. Баллы отражают силу приведённых подтверждений, а не рыночную стоимость компании. Если сведений нет, соответствующая оценка равна нулю. Результат сохраняется в профиле отдельным снимком и обновляет настроение Бруно; прежние снимки остаются в истории. Каждую оценку и пояснение можно доработать вручную.

Для автоматической оценки нужен настроенный AI-провайдер. Краткие ответы основателя передаются вместе с предшествующим вопросом Бруно, чтобы не терять их смысл; предположения Бруно не считаются фактами. GigaChat получает обязательную схему всех пяти оценок через [структурированный вывод API](https://developers.sber.ru/docs/ru/gigachat/guides/structured-output). Перед сохранением приложение проверяет наличие всех оценок, диапазон 0–100 и пояснения. Незавершённый или некорректный ответ автоматически запрашивается повторно один раз. Если повтор тоже не прошёл проверку или API недоступен, прежний радар не меняется.

## Проекты и прогресс

- «Мои проекты» хранит отдельные профили, разговоры и радары. Добавьте проект кнопкой сверху; карточки листаются свайпом, стрелками на экране или клавишами ←/→, когда карусель в фокусе. Стрелки доступны и на телефоне.
- Новые оценки содержат короткие цитаты и ссылки на исходные сообщения или описание проекта. Приложение сверяет цитаты с переданным контекстом. Метки отличают слова основателя, предположения и отсутствие данных; это не независимая проверка бизнеса. Старые оценки можно обновить для добавления источников.
- «Уточнить с Бруно» в строке таблицы открывает разговор по выбранному направлению. После уточнений нажмите «Составить таблицу» для нового снимка.
- «История радара» позволяет выбрать любую сохранённую версию, сравнить её с предыдущей и раскрыть старые и новые пояснения. Просмотр истории не меняет текущий профиль.
- Достижения выдаются за первую AI-оценку, сведения с источниками по пяти направлениям, доработку пояснений и рост AI-оценки с новой цитатой. Число сообщений и ручное повышение баллов наград не дают.

## Данные и ограничения MVP

- SQLite используется локально. Для PostgreSQL задайте `DATABASE_URL`.
- Оценки сохраняются снимками; текущее состояние Бруно рассчитывается по последнему снимку.
- Каждое сообщение основателя сохраняется как исходная заметка. Поиск старого контекста сейчас текстовый; `embedding_ref` оставлен для будущего векторного индекса.
- Поддерживаются UTF-8 TXT, MD, CSV и JSON до 2 МБ. В AI-контекст попадают первые 12 000 символов файла.
- Tailwind подключён через CDN для быстрой разработки; собственный CSS обеспечивает локальное оформление. Перед публичным развёртыванием Tailwind следует собрать локально.
- Этот запуск предназначен для локальной разработки. Перед публичным развёртыванием нужны отдельные настройки безопасности, домена, HTTPS, ограничений запросов и приватного файлового хранилища.


## Задания, дневник и инвестор

В профиле проекта доступны вкладки «Задания Бруно», «Дневник доказательств» и «Бруно-инвестор».

- Бруно подбирает до трёх активных заданий с учётом профиля, разговоров, последнего радара и дневника. В деморежиме используются готовые примеры. Задание можно отложить или завершить записью результата.
- Дневник хранит проверяемый тезис, наблюдение, дату, источник, результат проверки и следующий вопрос. Записи можно уточнять. Отрицательный результат также завершает задание. Сама запись баллов не добавляет: для новой оценки нажмите «Обновить радар с Бруно».
- Записи дневника входят в контекст обычного чата, радара и тренировки. Цитаты в радаре могут вести на запись дневника. Сведения остаются словами основателя, без автоматического подтверждения достоверности внешних источников.
- Инвестор задаёт вопросы о покупателе, цене, сделках, каналах привлечения и экономике продаж. По завершении сохраняется разбор ответов. Тренировочные сообщения исключены из памяти бизнес-фактов и контекста радара, включая старые записи памяти, созданные до этого обновления.

Новые данные: модели `BrunoTask` и `EvidenceEntry`, миграции `0005` и `0006`. Проверки: `.venv/bin/python manage.py test founder`.

## Карточки, сообщество и личные сообщения

- В чате или профиле нажмите «Оценить и собрать карточку». Бруно создаст новый радар и предложит краткое описание проекта по обычным разговорам, профилю и дневнику. Тренировки инвестора и личные сообщения других участников в контекст не входят. В деморежиме доступно ручное заполнение.
- В редакторе можно изменить любое поле вручную, увидеть предпросмотр или описать правку Бруно. Его ответ остаётся предложением в форме до сохранения. Версии защищены от перезаписи устаревшей вкладкой.
- «Сохранить черновик» оставляет изменения личными. «Опубликовать» сохраняет отдельный снимок для участников сообщества. Последующие правки не меняют публикацию до повторного нажатия. «Снять с публикации» скрывает карточку из ленты, поиска, избранного и прямых ссылок.
- Радар включается в публикацию отдельной галочкой: только баллы, источник оценки и дата, без приватных цитат и документов. Оценка относится к полноте сведений, а не к стоимости компании.
- В сообществе есть поиск, фильтр стадии, избранное, карточка автора и кнопка начала личного диалога. Карточки видны вошедшим участникам. Переписку видят только двое участников; она сохраняется и после снятия карточки с публикации.
- Личные сообщения идут через `/ws/messages/`: сессионная авторизация, проверка Origin и участника, история, восстановление после обрыва, защита от повторной отправки, непрочитанные и отметки чтения. Enter отправляет, Shift+Enter добавляет строку. Контакт можно заблокировать. Текст выводится без выполнения HTML.

Запуск остаётся прежним: `python manage.py migrate`, затем `python manage.py runserver`. Теперь команду обслуживает ASGI-сервер Daphne, чтобы поддерживать WebSocket. Для развертывания используйте, например, `daphne -b 127.0.0.1 -p 8000 config.asgi:application`, а на HTTPS-прокси включите передачу WebSocket Upgrade. WSGI-сервер личные сообщения не обслуживает.

Один локальный процесс использует встроенный канал в памяти; история всё равно хранится в базе. Для нескольких процессов, включая одновременные локальный и Telegram-серверы, запустите Redis и задайте одинаковый `REDIS_URL=redis://127.0.0.1:6379/0` обоим процессам. Это необходимо для мгновенной доставки между разными процессами ([документация Channels](https://channels.readthedocs.io/en/stable/topics/channel_layers.html)). На публичном сервере также нужны обычные настройки HTTPS, защищённых cookie и ограничения запросов на прокси.

Проверки сообщества и WebSocket: `python manage.py test founder.test_community`. Миграция `0007` добавляет карточки, избранное, диалоги, сообщения и блокировки; существующие проекты остаются приватными.
